# Text Compare

개발자용 텍스트/코드 비교 도구입니다. 기존 파일과 수정 파일의 내용을 비교해 변경 사항을 빠르게 확인할 수 있습니다.

## Live Demo

https://hyjun99.github.io/text_compare/

## 주요 기능

- 기존 파일 / 수정 파일 텍스트 비교
- 라인 단위 비교 및 라인 번호 표시
- 공백 변경 감지
- 실제 텍스트 수정 감지
- 신규 생성 라인 감지
- 삭제 라인 감지
- 변경 라인 전체 하이라이트
- 라인 내부 변경 문자 강조
- 이전 / 다음 변경점 이동
- 좌우 독립 비교 Pane
- 신규/삭제 라인 발생 시 반대편 placeholder로 정렬 유지

## 색상 구분

- 파랑: 공백 변경
- 주황: 텍스트 수정
- 보라: 신규 생성
- 빨강: 삭제
- 연두: 변경이 발생한 라인

## 사용 방법

1. 왼쪽 `기존 파일` 영역에 원본 코드를 입력합니다.
2. 오른쪽 `수정 파일` 영역에 변경된 코드를 입력합니다.
3. `비교하기` 버튼을 누릅니다.
4. 색상과 라인 번호를 통해 변경 사항을 확인합니다.
5. `이전` / `다음` 버튼으로 변경 지점을 이동할 수 있습니다.
